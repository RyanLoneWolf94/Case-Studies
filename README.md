## Structure

```
Case-Studies/
├── README.md                     ← this index
├── TEMPLATE.md                   ← copy this to start a new case study
└── case-studies/
    └── 01-illuminer-systems/
        ├── README.md             ← the case study
        └── assets/               ← logos, screenshots, decks
```

## Adding a new case study

1. Copy `TEMPLATE.md` into a new folder: `case-studies/NN-project-slug/README.md`
2. Drop supporting visuals into that folder's `assets/`
3. Add a row to the **Index** table above
