## 1. The Brief

The studio's own site — the shop window for a brand-and-dev business — needed to practise
what it preaches. I ran it as a **structured, five-phase audit-and-improvement project**
rather than ad-hoc tweaks, treating the LoneWolf site with the same rigour as a client
engagement.

**The core challenge:** take a functional but template-feeling WordPress/Elementor site
and make it demonstrably *LoneWolf* — correct, on-voice, and visually distinctive enough
to be its own best case study.

---

## 2. The Audit (Phase 1)

The audit surfaced concrete defects and UX issues, including:

- a **negative project counter**
- a **zero awards counter**
- a typo in the brand name (**"LoneWol,"**) and a repeated phrase
- UX problems on the **branding questionnaire**
- a broader critique that the design read as **template-heavy** rather than crafted

Framing it as an audit turned a vague "the site needs work" into a prioritised, trackable
backlog.

### Phase 2 — Copy overhaul
Every line rewritten into the **LoneWolf voice** — cheerful, witty, high-energy, with the
pack/territory metaphor set, layman-friendly but technically credible.

### Phase 3 — Homepage mockup
A restructured homepage: a **two-column hero**, a **stats bar**, a **services grid**,
**portfolio case-study cards**, and a **restructured footer** highlighting both the
**Hanoi and Harare** offices.

### Phase 4 — Animated v2 mockup
A second-generation mockup built in the **correct brand palette** (orange hero, white
body, purple testimonials, orange CTA, deep purple-black footer) with a full motion layer:

- text-scramble effect
- magnetic buttons
- mouse-parallax background blobs
- a scroll-triggered nav morph
- animated stats counters
- scroll-reveal transitions

---

## 5. Process & Direction

```
Structured audit  →  Bug & typo fixes  →  Brand-voice copy overhaul
   →  Homepage layout mockup  →  Animated v2 mockup (brand palette + motion)  →  Phase 5
```

The redesign doubles as an **experiment**: testing how far current AI tooling can be
pushed to match human-level craft, benchmarked against high-end interactive studio sites.
The intent is a self-built redesign that proves the studio's own capability — the LoneWolf
site as its own flagship case study.

---

## 6. Outcome

The LoneWolf site has moved from a template-feeling, error-carrying page to a **corrected,
on-voice, visually distinctive** property across its first four phases: bugs fixed, copy
rewritten in brand voice, and an animated, correctly-palette'd homepage and portfolio
direction delivered. Phase 5 remains to close out the overhaul. The project stands as the
studio applying its own branding-and-development discipline to itself.
